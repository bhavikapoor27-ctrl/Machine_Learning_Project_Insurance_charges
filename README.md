# Insurance Charges Prediction using Linear Regression

## 📌 Overview
This project uses **Linear Regression**, a supervised Machine Learning algorithm, to predict medical insurance charges based on customer features.

## 🛠️ Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Google Colab

## 📊 Dataset Features
The dataset includes customer attributes such as:
- Age
- Sex
- BMI
- Number of children
- Smoking status
- Region

**Target Variable:** `charges`

## ⚙️ Workflow
1. Data loading and preprocessing
2. Exploratory Data Analysis (EDA)
3. Encoding categorical variables, if required
4. Train-test split
5. Linear Regression model training
6. Insurance charge prediction
7. Model evaluation

## 🧠 Key Learnings
- Linear Regression
- Data preprocessing
- Feature encoding
- Model training and prediction
- Regression evaluation metrics
